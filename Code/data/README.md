# Experiment data

All experiment CSVs are stored here so runs do not depend on sibling repositories or network access. Configured `data_path` values are resolved relative to the `Code/` directory. Generated predictions, checkpoints, logs, and other run outputs belong under `Results/` and are intentionally excluded from Git.

| File | Used for | Source / generation |
|---|---|---|
| `simulation_gene_data.csv` | Simulation Gene experiments | DeepRUOT official data, pinned source revision [`e9b06bca`](https://github.com/zhenyiizhang/DeepRUOT/blob/e9b06bca530b4f442c829692bf43b656d0a1af4e/data/simulation_gene_data.csv). |
| `mouse_hematopoiesis.csv`, `emt.csv` | Mouse and EMT experiments | DeepRUOT data release: [Mouse](https://github.com/zhenyiizhang/DeepRUOT/blob/main/data/mouse_hematopoiesis.csv), [EMT](https://github.com/zhenyiizhang/DeepRUOT/blob/main/data/emt.csv). |
| `wfr_fm_dygen.csv` | Dygen experiments | WFR-FM official data: [dygen.csv](https://github.com/QiangweiPeng/WFR-FM/blob/main/data/dygen.csv). |
| `cite_pca50.csv`, `eb_noscale.csv`, `Weinreb_alltime.csv` | Experiment 2 and hold-one-out experiments | WFR-FM release data folder: [QiangweiPeng/WFR-FM/data](https://github.com/QiangweiPeng/WFR-FM/tree/main/data). These files are bundled locally to make the experiments reproducible without checking out WFR-FM or Baselines. |
| `lowdim_action_benchmarks/*.csv` | Low-dimensional action benchmarks | Generated by `scripts/generate_lowdim_action_benchmarks.py` with its recorded fixed seed. |

Please retain these source citations when reusing or redistributing the datasets and check the original dataset terms. The CSVs are data inputs, not model weights or experiment outputs.
